# Project Overview

Fullstack Pharmacy Management System

## Frontend

- React
- Vite
- TailwindCSS
- Axios

## Backend

- NodeJS
- ExpressJS
- Prisma ORM
- PostgreSQL
- Redis

## Authentication

- JWT Access Token
- Refresh Token stored in HttpOnly Cookie

## Authorization

- RBAC

Roles:

- ADMIN
- PHARMACIST
- CUSTOMER

## Coding Rules

- Use ES Modules
- Use async/await
- Use Prisma for all database access
- Validate request data before processing
- Keep controller thin
- Business logic goes into service layer
